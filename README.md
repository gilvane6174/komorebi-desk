# こもれびデスク v0.1.0

**仕事も、お店も、くらしも。自分のペースで記録できる、ひとつの机。**

フリーランス・お店・サロン・教室・創作・福祉・くらし向けの機能を体験でき、用途別の12の版で整理できる個人・フリーランス・事業者・施設などが、私生活にも日常業務にも無料で使える記録ツールです。HTMLファイル1つで動き、登録も広告もありません。記録はあなたの端末のブラウザの中だけに保存されます。

> インストールするアプリではなく、ブラウザで開く**記録ツール**（HTMLファイル）です。パソコン・スマホ・タブレットのブラウザで開けます。

> **最初に読んでください**：本ソフトは補助ツールです。個人・施設など想定される用途を問わず、実際の情報を入れる前に [SAFE_USE_GUIDE.md](SAFE_USE_GUIDE.md) を確認してください。職員ごとのアクセス制御はなく、安全性の認証を受けた本番システムではありません。任意のGoogle Drive導入キットは説明資料のみで、Googleへの自動アクセス機能はありません。

> **利用条件の重要事項**：ソースコードを公開していても、オープンソースライセンスではありません。個人利用・業務上の通常利用は無料で許可します。一方、ソフト自体の改変・再配布・販売・転用は禁止しています。詳しくは [LICENSE](LICENSE) を確認してください。

## 3つの約束
1. **登録しない**：アカウントもメールアドレスも要りません。
2. **外へ送らない**：記録を送信しません。ブラウザの機能（CSP）で通信を止めています。ツールの設定画面で、通信の回数を自分で確かめられます。
3. **データはあなたのもの**：バックアップ（JSON）とCSVで、いつでも書き出せます。形式は [DATA_FORMAT.md](DATA_FORMAT.md) にあります。

## はじめかた
1. Releases または配布ZIPから「単体利用_12版一式」を保存して展開します。
2. `index.html`（紹介ページ）か `start-here.html`（はじめての手引き）を開き、自分に合う版を選びます。
3. 選んだ `komorebi-○○.html` をブラウザで開きます。最初は架空のサンプルが入っています。眺めたら「サンプルを消して始める」を押してください。
4. 保存場所（フォルダとブラウザ）を決めたら、動かさずに使います。ときどき「全体バックアップ」を取ってください。

## 主な機能
- **共通**：一覧と編集フォーム、まとめて編集、ひな形・定型文、元に戻す（Ctrl+Z）、探す・操作（Ctrl+K）、検索・CSV・印刷、暗号化できる全体バックアップ、ロック、年度の変わり目のお知らせ、ふりかえり
- **フリーランス**：工数・請求・帳簿・確定申告の準備、明細CSVの取り込みと仕分けルール
- **お店・現場**：サロンの予約表と来店周期、小売のABC分析・廃棄・発注書、教室の未納・振替、制作の原価・利益、訪問のチェックリスト・報告書
- **創作**：執筆ペース、締切カレンダー、販売照合
- **くらし**：体調と働き方の重ね合わせ、受診時に見せる1か月のまとめ、医療費の上限、年金・制度の期限
- **福祉**：事業所の期限・計画・実績・工賃・研修・月次集計、支援者の申し送り・支援記録、本人のひとつずつ記録
- **シフト**：休み希望と勤務形態から負担の偏らない案を作成、印刷、祝日の扱いと追加の休日

## 位置づけ・向いている規模
- **個人・単独の担当者（または同じ権限の少人数）向けの記録補助**です。1台の端末で使います。職員ごとの権限・ログイン・変更者の記録（監査ログ）はないため、**施設全体の正式な記録基盤の代わりには使わないでください**。
- 1つの表は5,000件まで。毎日1人1件の記録なら、13人で約1年、100人なら約50日で上限です。
- 容量が7割を超えると知らせます。設定の「保存容量」から、古い月の記録を保管ファイルへ移せます。
- 実データを入れるなら設定の「ロック」をオンにしてください。同じブラウザで開いた別のHTMLファイルから読まれるおそれがあるためです。ロックは保存データそのものを暗号化しますが、端末を操作できる人による保存領域の差し替え・巻き戻しは防げません。詳しくは [SECURITY.md](SECURITY.md)。
- 利用者・顧客・家族など**他人の情報**を入れる場合は、説明と同意、必要最小限の項目、保存期間を運用者が決めてください。他人の情報を含むファイルを外部のサービスやAIへ渡すことは、運用者による外部提供に当たる場合があります。

## できないこと
- 電子申告・正式な複式簿記
- 国保連請求・配置基準の判定
- 医療の診断・受給資格の判定
- 自動送信・自動同期

計算は目安です。くわしくは、ツールの「ご利用にあたって」を見てください。

## AI・botと使う（任意）
使わなくても、すべての機能が使えます。

- **手渡し方式**：依頼ファイルを自分でAIに渡し、提案を確認して反映します。詳細は「AI・Drive導入キット」の手渡し方式の説明を参照してください。
- **担当の呼び名**：Atlas（全体整理）、Aegis（公開前点検）、Quill（編集・校正）など、役割ごとの呼び名の例を用意しています。名前を分けてもAI側の権限や利用枠は分かれません。
- **Google Drive導入キット**：`DRIVE_START_KIT.zip`。説明資料のみです。Apps Script の実行コード・夜間自動更新機能は付属しません。

## 開発・確認
- 追加のインストールは要りません（Node.js 18 以上）。
- ビルド：`node tools/build.cjs`（`dist/` に12版・紹介サイト・rates.json・説明資料のZIPができます）
- チェック：`node tools/check.cjs`（CSP・スクリプトのハッシュ・外部リソース）
- テスト：`node tests/calc.cjs`。ブラウザのテストは Playwright のある環境で `tests/*.cjs`
- 配布ZIP：`node tools/package.cjs`（ビルド後）
- 構成：`src/core/`（共通部品）、`src/mod/`（1画面1ファイル）、`editions.json`（版ごとの画面の組み合わせ）

### 公開サイトと「最新情報に更新」
- 紹介サイトは、GitHub Actions の **publish-site** を手動で実行したときだけ公開されます。
- 公開サイトでビルドした版にだけ、「最新情報に更新」の取得先（そのサイトの `rates.json` の1か所）が入ります。押して確認したときにだけ読みます。ほかの版はファイルからの読み込みだけです。
- 年度が変わったら、`src/core/calc.js` の `DEFAULT_RATES` を公式の値に更新して、publish-site を実行します。

## 『こもれび』の名前に込めた思い

会社や施設、お店などでの管理作業を、少しでも楽にできる場所にしたい。忙しい仕事の途中でも画面を開くと気持ちが落ち着くような、木漏れ日の差すオアシスをイメージして『こもれびデスク』と名付けました。

## その他の機能

- すべてのシフトを使える版：日付ヘッダー下の「＋備考」から、その日の会議・行事・共通連絡を登録。全員用と個人用の印刷にも表示。
- すべての版：ホームに直接書ける「すぐメモする」と、日付で絞り込む「メモ」一覧。
- 福祉施設／支援者版：預り金・購入管理、利用者別残高、領収書写真、一件ごとの印刷報告書と編集可能な印刷テンプレート。
- 福祉施設／支援者版：利用者別服薬確認メモと架空の薬サンプル。正式な処方・投与記録の代わりにはしない。
- 支援者版：ヒヤリハット・事故を個別に印刷。帳票の文章を変更可能。
- サロン版：お客様ごとの髪型写真・イラスト画像をカルテに添付して個別印刷。印刷テンプレート編集可能。
- 年金・制度版：児童扶養手当、生活保護の母子加算、障害福祉関連等の確認候補を拡充。実際の受取・更新期限を制度名で紐付け。受給資格は判定しない。

**写真とプライバシー**：画像は選択時に縮小・JPEGへ変換し、記録データに含めて端末内に保存します。位置情報EXIFは再符号化で保持しません。大きな画像は受け付けず、保存容量には限りがあります。写真を含むバックアップには個人情報が含まれるため、ロックと暗号化バックアップを推奨します。写真そのものはCSVには出さず、JSONバックアップに含まれます。

**検証上の制約**：12版の生成、JavaScript構文、CSPとハッシュ検査は実施済み。ブラウザ実機の操作・印刷についてはこの作業環境のブラウザ起動制限のため未完了。配布・公開前に実機確認を推奨します。
