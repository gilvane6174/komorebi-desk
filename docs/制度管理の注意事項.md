# 制度・年金・手当の記録について

本ツールは受給の可否・金額・併給条件を自動判定しません。制度一覧は「思い当たる制度を見落とさず、自治体や窓口へ確認した結果を記録する」ための候補です。国のすべての制度、自治体独自の制度、今後の法改正を網羅するものではありません。

確認用の一次情報（2026年10月22日時点に確認）：

- こども家庭庁・ひとり親家庭等関係 https://www.cfa.go.jp/policies/hitori-oya
- こども家庭庁・児童扶養手当 https://www.cfa.go.jp/policies/hitori-oya/fuyou-teate/
- 厚生労働省・治療と仕事の両立（医療費支援等） https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000115267.html

## 記録上の使い方
1. 「使える制度のメモ」へ制度名、担当窓口、公式URL、確認状況、確認額、次回確認日を記録する。
2. 「年金・手当の受給記録」へ実際の受取額のみ入力し、関連制度名を同じ表記にする。
3. 「書類・更新の期限」へ期限を登録し、関連制度名を同じ表記にする。
4. 「制度と入金・期限の紐付け」で関連する受取記録と直近期限を確認する。

※母子加算は生活保護における加算であり、児童扶養手当とは異なります。両制度の扱い・金額は担当窓口へ確認してください。
