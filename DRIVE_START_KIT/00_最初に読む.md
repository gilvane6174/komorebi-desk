# Drive・AI活用の説明キット（コードなし）

この公開版には、Google Apps Script の実行コード・`Code.gs`・マニフェスト・夜間自動更新は付属しません。Google Driveへの書き込み、AIへの依頼、同期、復旧は自動実行されません。

記録はまずローカルHTMLに保存し、利用者本人が必要に応じて匿名化済みデータを確認し、Drive等へ手動で保管します。写真や服薬・金銭・顧客情報を含む記録は、共有範囲と内容を特に注意してください。

以下は将来構想・手動運用の説明です。存在しないスクリプトをネットから探して貼り付けたり、広いDrive権限を承認したりしないでください。

ZIPを全展開し、このフォルダごとGoogle Driveの「フォルダをアップロード」で一括配置します。HTMLだけをDriveへ置いてもブラウザ内の記録は移りません。最初は架空データで試してください。

## 2つの使い方
- 単体版：HTMLを開いて入力。各画面の計算とホームの期限・発注点が自動連動。AI契約・通信不要。閉じている間は動かず、開き直した時の記録から再集計します。
- Driveでの手動保管：出力した集計JSONの内容を確認して、必要なら01_集計へ手動アップロードできます。夜間レポートは自動生成されません。

AI・botを使う場合は、許可したデータを02_AI依頼へ配置し、担当別の依頼文をサービスの定期実行へ設定。出力先は03_AI提案。自動更新するのは確認用レポート・下書き・変更案で、ローカルの元記録は人が差分を確認して反映します。

本公開版には自動実行機能がありません。02_夜間更新の設定.mdは構想と注意事項のみです。

全12版・フル17機能。担当別設定は創作・仕事・デザイン・ツール支援にも対応。担当は「役割の例」です。初回は整理役（Atlas）と、必要な実作業の役1つだけで始めると、重複や利用量を減らせます。起動順は依頼→担当の下書き→点検→人の承認→記録。全部の役を使う必要はありません。
