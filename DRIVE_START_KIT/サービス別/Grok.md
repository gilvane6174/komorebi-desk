# Grok（xAI）を利用する場合

確認日：2026-10-20。以下は運用者が選択する連携方法の紹介で、接続・契約を自動で行うものではありません。

Grok Botは外部サービス上のクラウド環境で作業するAIです。公式説明では同一運用者の複数Botがファイル・ブラウザ・ログインを共有します。担当名を分けても権限は隔離されません。専用の依頼ファイルだけを指定し、提案作成までを依頼する運用例にしてください。Driveにログインできることを全フォルダへの許可と解釈しないでください。こもれびデスクとの直接同期はありません。公式Driveコネクタと定期実行の説明があります。アカウント別の利用可否・実行中の書込制限を実画面で確認し、02_夜間更新の設定.mdに沿って単発テスト後に設定してください。

Drive公式：https://docs.x.ai/grok/connectors/google-drive
定期実行公式：https://docs.x.ai/grok-bot/skills-routines-and-automations

公式：https://x.ai/bot
現行契約と上限：https://docs.x.ai/x-subscription/grok-bot
料金：https://x.ai/pricing
旧SuperGrok等とThe X Subscriptionでは利用枠の扱いが異なる場合があります。契約の移行・追加課金は本人が別途判断してください。

全サービス共通：外部へ渡した情報には相手側の保存・学習・利用規約が適用されます。不要な個人情報・バックアップ・認証情報を渡さず、元データを直接編集させない運用を推奨します。

定期実行と単発の会話では使える操作が異なる場合があります。自動化の成否は初回の定期結果まで確認してください。
