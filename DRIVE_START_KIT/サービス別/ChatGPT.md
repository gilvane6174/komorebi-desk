# ChatGPTを利用する場合

確認日：2026-10-20。以下は運用者が選択する連携方法の紹介で、接続・契約を自動で行うものではありません。

公式Google Driveプラグインを利用できる環境では、対応するDrive資料の検索・要約・下書きの素材取得などを依頼できます。利用可能なアプリと操作はプラン・地域・管理者設定によって異なるため、画面の説明を確認してください。こもれびデスクの依頼JSONは本人がアップロードするか、ファイル添付で渡します。提案JSONを新規ファイルとして返すよう依頼します。

公式：https://openai.com/business/plugins/google-drive/
管理と権限：https://help.openai.com/en/articles/11509118-admin-controls-security-and-compliance-for-plugins-and-apps
ファイル上限：https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt
文書512MB、テキスト200万トークンなどの種類別上限がありますが、本ツールの提案取込は1MB以内・100行以内です。サービスの上限まで詰め込む必要はありません。

全サービス共通：外部へ渡した情報には相手側の保存・学習・利用規約が適用されます。不要な個人情報・バックアップ・認証情報を渡さず、元データを直接編集させない運用を推奨します。

定期実行と単発の会話では使える操作が異なる場合があります。自動化の成否は初回の定期結果まで確認してください。
