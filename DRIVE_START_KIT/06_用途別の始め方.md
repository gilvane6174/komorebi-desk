# 新しい3用途の始め方

|対象|単体でできること|AIへの依頼例|
|---|---|---|
|小規模教室・個人講師|授業・出欠・振替・月謝を入力し、月別未入金と準備期限を確認|受講者IDだけで、教材準備の順序と振替候補の確認事項を整理|
|ハンドメイド・受注制作|注文工程・納期、材料の累計入庫と使用を入力。残量と補充候補を自動表示|匿名の注文IDと工程から制作順の案を作成|
|清掃・訪問サービス|現場IDで予定・見積・実費・作業前後の確認と再訪期限を管理|現場IDと期限から未完了の確認一覧を整理|

フル版にも同じ機能があります。個別版との移行は全体バックアップを保存して復元します。

1. index.htmlから版を選び、架空サンプルを確認。サンプルを消して実用を開始。
2. 単体ではホームが期限と材料不足を自動集計。請求・帳簿への転記は人が照合。
3. Driveへの保管は任意です。集計JSONの内容を確認し、必要なファイルだけを01_集計へ手動アップロードしてください。
4. Apps Scriptコード・夜間自動処理は本公開版に含まれません。インターネット上の未検証コードを代わりに実行しないでください。
5. AIには設定画面で必要な表・項目だけを選び依頼JSONを渡し、返答の差分を確認して反映。役割の例から担当を選べます。

実名・学校名・連絡先・訪問住所・鍵・暗証番号は入力せずIDを利用してください。費用差額は人件費・設備費・税を含まず利益ではありません。サービス料金・制限は同梱料金表の確認日と公式リンクを参照。

## 創作・自己出版
作品IDを作品・章・公開・権利・販売・制作費・紙の本在庫で共通利用。報告受取額は手数料等控除後の明細額、入金は実日付を記録。AIはInkwellが下書き、Quillが編集、Hueがデザイン、Aegisが公開前点検、Abacusが売上・費用の照合、Atlasが引継ぎを担当できます。必要な担当だけ指定してください。成果・売上は保証されません。
